# โปรแกรมค้นหาและเบลอ IP/MAC ในรูปภาพ

สคริปต์ `redact_network_ids.py` ใช้ Tesseract OCR อ่านข้อความในภาพ แล้วค้นหา IPv4, IPv6 และ MAC Address พร้อมพิกัดกรอบข้อความ จากนั้นใช้ ImageMagick เบลอเฉพาะกรอบข้อความที่พบในไฟล์ผลลัพธ์ ต้นฉบับจะไม่ถูกแก้ไข

รองรับ `.jpg`, `.jpeg` และ `.png` เลือกไฟล์หลายไฟล์ เพิ่มโฟลเดอร์ input ได้หลายโฟลเดอร์ และสแกนทุก subfolder แบบ recursive ผลลัพธ์เก็บโครงสร้างโฟลเดอร์ย่อยไว้ใต้โฟลเดอร์แยกตาม source เช่น `source_1_Photos` เพื่อป้องกันชื่อไฟล์ซ้ำทับกัน

## ติดตั้ง

1. ติดตั้ง Python 3.10 ขึ้นไป
2. ติดตั้ง Tesseract OCR และภาษา `English` (หน้าจอ Windows มักแสดงชื่อ field เป็นภาษาอังกฤษ แม้ระบบจะเป็นภาษาไทย; เพิ่มข้อมูลภาษา Thai ได้หากจำเป็น) แล้วเพิ่มตำแหน่ง `tesseract.exe` เข้า PATH
3. ติดตั้ง ImageMagick โดยเลือกตัวเลือกเพิ่มโปรแกรมเข้า PATH ระหว่างติดตั้ง ตรวจสอบว่ารันคำสั่ง `magick -version` ได้
4. เปิด PowerShell ในโฟลเดอร์ที่บันทึกสคริปต์ แล้วติดตั้ง Python packages:

```powershell
python -m pip install Pillow pytesseract
```

ตรวจสอบโปรแกรมภายนอก:

```powershell
tesseract --version
magick -version
```

## ใช้งานแบบ GUI

ดับเบิลคลิก `setup_and_run.bat` เพื่อให้ไฟล์ตรวจสอบและติดตั้งแพ็กเกจ Python (`Pillow`, `pytesseract`) จากนั้นเปิด GUI ให้โดยอัตโนมัติ หน้าต่างหลักแสดงรายการ Input/Output, จำนวนไฟล์, progress bar, สถานะต่อไฟล์, address ที่ตรวจพบ และ log พร้อมปุ่มหยุดและเปิดโฟลเดอร์

GUI เริ่มต้นเป็นภาษาอังกฤษ กดปุ่ม **THAI** มุมขวาบนเพื่อเปลี่ยนเป็นภาษาไทย และกด **ENG** เพื่อกลับเป็นภาษาอังกฤษ

ในช่อง Input กด **เพิ่มโฟลเดอร์** ซ้ำเพื่อเพิ่มหลายโฟลเดอร์ได้ โปรแกรมรวมภาพจาก subfolder ทั้งหมดให้อัตโนมัติ หรือกด **เพิ่มไฟล์** เพื่อเลือกหลายภาพพร้อมกัน กด **ลบที่เลือก** เพื่อนำ source ที่เลือกออกจากรายการ เมื่อกด **เลือกโฟลเดอร์** ในช่อง Output จะเก็บตำแหน่งหลักไว้ก่อน พอกด **เริ่มประมวลผล** โปรแกรมสร้าง `output_YYYYMMDD_HHMMSS` ที่นั่น ทดสอบเขียนไฟล์ และแสดงพาธ export จริงในช่อง Output งานจะ export ลงโฟลเดอร์นี้โดยตรง หากสร้างไม่ได้จะแจ้ง error ทันที

### โหมด Fixed Area

เลือก **Fixed Area: ใช้พื้นที่เดียวกันทุกภาพ** แล้วกด **เลือกพื้นที่จากภาพแรก** โปรแกรมเปิดภาพแรกในรายการ Input ให้ลากเมาส์ครอบบริเวณที่ต้องการเบลอ จากนั้นกด **ใช้พื้นที่นี้** เมื่อเริ่มประมวลผล โปรแกรมจะเบลอพิกัดเดียวกันในทุกภาพโดยไม่เรียก OCR พื้นที่ถูกเก็บเป็นสัดส่วนของภาพ จึงปรับตามภาพขนาดต่างกันได้ดีที่สุดเมื่อภาพมี layout และ aspect ratio ใกล้เคียงกัน หาก layout ต่างกันควรใช้โหมด OCR หรือกำหนดกรอบใหม่

ก่อนเริ่ม OCR โปรแกรมตรวจจำนวนภาพ, สร้างโฟลเดอร์ export, ทดสอบสิทธิ์เขียน และตรวจว่าแผนพาธผลลัพธ์ทุกไฟล์อยู่ภายในโฟลเดอร์ export และไม่มีชื่อซ้ำ หากกดเริ่มมากกว่าหนึ่งครั้งในวินาทีเดียว โปรแกรมจะเพิ่มท้ายชื่อเป็น `_01`, `_02` เพื่อไม่ให้ชนกับรอบก่อน

หรือรันผ่าน PowerShell เพื่อเปิด GUI:

```powershell
python .\redact_network_ids.py
```

เลือกว่าจะใช้ไฟล์หรือโฟลเดอร์ต้นทาง จากนั้นเลือกโฟลเดอร์ส่งออก ผลลัพธ์ใช้ชื่อเดิมต่อท้าย `_redacted` เช่น `photo_redacted.jpg`

## ใช้งานผ่าน command line

```powershell
python .\redact_network_ids.py "C:\images\input" "C:\images\redacted"
python .\redact_network_ids.py "C:\images\screen.png" "C:\images\redacted"
```

หาก Tesseract ไม่อยู่ใน PATH ให้ระบุพาธ และถ้าต้องการภาษาไทย:

```powershell
python .\redact_network_ids.py "C:\images\input" "C:\images\redacted" --tesseract-cmd "C:\Program Files\Tesseract-OCR\tesseract.exe" --lang eng+tha
```

รัน OCR เพื่อตรวจสอบรายการและพิกัดก่อน โดยไม่สร้าง/แก้ไขภาพ (ไม่แสดง GUI):

```powershell
python .\redact_network_ids.py "C:\images\input" "C:\images\redacted" --preview
```

## หมายเหตุ

- โปรแกรมเบลอกรอบที่ตรวจพบด้วย Gaussian blur การเบลออาจยังไม่เพียงพอต่อการปกปิดข้อมูลที่มีความอ่อนไหวสูง ควรตรวจสอบผลลัพธ์
- OCR อาจอ่านตัวอักษรหรือเครื่องหมายวรรคตอนผิด และกรอบอาจคลาดเคลื่อนได้ ควรตรวจไฟล์ผลลัพธ์ทุกครั้ง โดยเฉพาะข้อมูลที่ต้องปกปิดอย่างครบถ้วน
- ตรวจ IPv4 ที่แต่ละ octet อยู่ระหว่าง 0–255, IPv6 ทั้งแบบเต็ม/ย่อ (รวม zone ID) และ MAC แบบ `AA:BB:CC:DD:EE:FF` หรือ `AA-BB-CC-DD-EE-FF`
- เพิ่มความเร็วโดยเริ่ม OCR สองรอบ และทำรอบ threshold เพิ่มเฉพาะภาพที่ยังไม่พบ address; ยังอาจพลาดได้เมื่อข้อความถูกตัดขอบหรือมีความละเอียดต่ำ
- หาก OCR ตรวจพบข้อความที่ไม่ใช่ข้อมูลอ่อนไหวตรงรูปแบบข้างต้น จะไม่ถูกปิดทับ
- หากไฟล์ชื่อซ้ำในโฟลเดอร์ผลลัพธ์ อาจถูกเขียนทับด้วยชื่อผลลัพธ์เดิม ควรใช้โฟลเดอร์ส่งออกแยกสำหรับแต่ละชุดงาน
